# Certificate Lifecycle Monitoring Tools

This directory contains all certificate lifecycle monitoring and analysis tools.

## 🔧 Tools

### ⚡ Quick Status Check
- **`cert-quick-status.sh`** - Fast 30-second overview of certificate lifecycle health

### 🔍 Comprehensive Analysis  
- **`cert-lifecycle-status.sh`** - Complete end-to-end certificate lifecycle monitoring

### 📊 PowerShell Deep Analysis
- **`cert-lifecycle-events.ps1`** - Advanced event correlation and job analysis with PowerShell

### 🔎 Job Investigation
- **`investigate-job-output.ps1`** - Detailed analysis of specific automation jobs

## 🚀 Quick Start

```bash
# Fast health check
./cert-quick-status.sh

# Comprehensive analysis
./cert-lifecycle-status.sh

# PowerShell detailed analysis
pwsh ./cert-lifecycle-events.ps1 -Detailed

# Specific job investigation
pwsh ./investigate-job-output.ps1
```
